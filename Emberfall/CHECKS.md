# Проверки Emberfall

Проверяется оригинальная браузерная MOBA с автономным и серверным режимами. Это игровой проект, не полная копия Dota 2.

## Фактически выполнено

- 13 групп симуляции: все 24 умения, мана/перезарядка, покупки и усиления, опыт/уровни, смерть/возрождение, помощь, прерываемый возврат, защита и порядок разрушения башен, ядро, детерминизм и восстановление из JSON.
- Три полных матча ботов закончились реальным уничтожением ядра за 478,75 / 654 / 698,5 секунды модельного времени; побеждали обе команды.
- 6 групп приложения: настоящие обработчики DOM, начало/пауза/настройки/возврат/результат/повтор, выбор героя, покупки, навыки, сетевые seq/auth и снимки. VM с минимальным DOM проверяет поведение, а не внешний вид.
- Геометрия Canvas: прямое/обратное преобразование координат, DPR, кэширование, компактный размер, состояния героев, эффекты, миникарта. Реальная растеризация Canvas просмотрена отдельно.
- 11 серверных групп: реальный HTTP с двумя независимыми клиентами через два сервиса с общей SQLite/D1-базой; движение, щит и потеря здоровья, одинаковое состояние, авторизация, изоляция, лимиты, CAS и повтор команд.
- 5 тестов готового Worker ESM: встроенные HTML/CSS/JS совпадают с исходниками; автономный HTML; HEAD/404/405/503; исходный телефон по /phone; две независимые сессии используют общую SQLite-базу.
- Настоящий браузер: выбор героя, матч с ботами, лавка и покупка, пауза; две вкладки вошли в общую комнату по коду, начали один матч и показали одинаковые время и счёт. Сетевая способность списала ману и запустила перезарядку. Ошибок JavaScript в этих сценариях не обнаружено.
- Смотрелись настольный интерфейс 1191 × 764 и компактный 390 × 844: меню прокручивается по вертикали, в компактном матче миникарта, четыре навыка и инвентарь доступны одновременно. Автономный HTML отдельно открылся в браузере через HTTP без загрузки внешних скриптов и стилей.
- Публичное размещение версии 1 подтверждено платформой. Шесть HTTPS GET вернули 200; CSS, три JS-файла и автономный HTML совпали по SHA256 с исходниками. Главная страница содержит точную разметку приложения и отдельно распознанную вставку браузерной проверки Cloudflare.
- На реальном опубликованном сервере прошли девять проверок с двумя независимыми HTTPS-клиентами: комната/вход, авторизация и права ведущего, 5×5 с восемью ботами, покупки/повторы команд, щит/мана/восстановление, движение и урон с оглушением во втором клиенте, отсутствие токенов в снимках, выход и удаление комнаты. Для щита Астера мана изменилась 420 → 365, щит составил 170. Второй клиент наблюдал перемещение на 1057,61 единицы. При E с расстояния 400 единиц сервер зафиксировал источник урона и оглушение 1,1 секунды; второй клиент увидел потерю здоровья. Разность здоровья между снимками может также включать действия ботов, поэтому не выдаётся за точный урон одной способности.
- После выхода обоих тестовых игроков сервер вернул `404 room_not_found`: временная комната удалена. Создана ровно одна тестовая комната, секреты и токены в отчёт не включены. Подробности — `online-verification.json`.

## Как повторить

Архив дополнительно распакован в отдельную новую папку: сборка и все 19 проверок Node test runner прошли без использования рабочей папки автора. Отдельные файлы проверок содержат также группы сценариев движка и интерфейса, поэтому число внутренних сценариев больше числа проверок runner.

Node.js 22.13+ (здесь использован 24.19), без npm-зависимостей:

```
node build.mjs
node --test
```

Локальные сетевые тесты открывают кратковременные HTTP-слушатели на 127.0.0.1 и закрывают их в finally. Для браузера запустите START_SERVER.cmd, затем откройте показанный адрес. Проверки Worker используют реальный SQLite через адаптер с интерфейсом D1. Они не обращаются к облачной базе.

## Что ещё нужно подтвердить

- Соединение через интернет с другого физического устройства пока не проверено.
- Автономный режим проверен по встроенным ресурсам и приложению с протоколом file в VM. Запуск file:// автоматизированным браузером ограничен средой; браузерная проверка того же автономного HTML проводится через локальный HTTP.

Скриншоты в screenshots сделаны в настоящем браузере, без подмены интерфейса изображениями. Файлы 01–05 относятся к локальному предпросмотру; 06 показывает автономный матч на публичном сайте, 07 — опубликованное меню. Сетевые действия на облачном сервере подтверждены HTTPS-отчётом, а не этими изображениями.
