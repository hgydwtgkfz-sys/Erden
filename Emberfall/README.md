# Emberfall

Публичная версия: **https://emberfall-battle-for-origin.quietchub17.chatgpt.site**. Для игры без интернета откройте `Emberfall.html` из комплекта. Исходники: https://github.com/hgydwtgkfz-sys/Erden/tree/main/Emberfall.

Оригинальная браузерная MOBA на русском языке: три линии, две команды по пять героев, шесть героев и 24 активные способности. Свободные места занимают боты. Цель — пройти башни хотя бы одной линии и разрушить вражеский Исток. Матч рассчитан примерно на 8–15 минут; действия игроков меняют его длительность.

## Быстрый запуск без интернета

1. Распакуйте архив целиком в обычную папку.
2. Дважды нажмите **START_OFFLINE.cmd** или откройте **Emberfall.html** в современном настольном браузере.
3. Выберите героя и сложность, оставьте режим игры с ботами и начните матч.

Установка и Node.js для автономного HTML не нужны. Файл содержит интерфейс, графику, звук и игровую логику; внешние изображения и музыка не загружаются. Если `Emberfall.html` ещё не собран, launcher откроет `public/index.html`: при этом папку `public` необходимо сохранить целиком. Автономная версия не подключает сетевые комнаты через `file://`.

## Сетевая игра на одном компьютере

Нужен **Node.js 22 или новее**; для полного набора тестов — **22.13+**. Внешние npm-пакеты не используются, `npm install` не нужен.

1. Запустите **START_SERVER.cmd**. Оставьте появившееся окно открытым.
2. Откройте **http://127.0.0.1:4173** в браузере.
3. Выберите сетевой режим, героя и имя; создайте комнату.
4. На этом же компьютере во второй вкладке или другом браузере откройте тот же адрес. Введите код комнаты и присоединитесь. Сетевая сессия хранится отдельно для каждой вкладки; настройки оформления на одном браузере общие. Для другого устройства используйте инструкцию «Игра в одной локальной сети» ниже.
5. Создатель комнаты начинает матч. Всего доступно 10 человеческих мест, по 5 на команду; недостающие участники становятся ботами.

Сервер управляет боем и проверяет команды; браузеры получают общее состояние примерно каждые 250 мс. При закрытии сервера локальные комнаты исчезают: этот launcher использует оперативную память. Остановить сервер можно `Ctrl+C` в его окне. Если порт 4173 занят, закройте прежний экземпляр или запустите вручную с другим `--port` и откройте соответствующий адрес.

## Игра в одной локальной сети

На компьютере ведущего запустите **START_LAN.cmd**. Он явно включает прослушивание `0.0.0.0:4173`. На втором устройстве в той же доверенной сети откройте `http://<IPv4-компьютера-ведущего>:4173`, например адрес из `ipconfig`, затем войдите по коду комнаты. Адрес `127.0.0.1` на втором устройстве указывает на него самого и для подключения к ведущему не подходит.

Launcher не меняет брандмауэр и маршрутизатор. Если устройства не соединяются, проверьте одинаковую сеть, IPv4 и разрешение входящего порта в Windows. Этот HTTP-сервер предназначен для локальной разработки и доверенной LAN. Доступ с другого физического устройства отдельно не подтверждён; проброс порта и публичный интернет-сервер здесь не настроены.

## Управление

| Действие | Клавиша / мышь |
|---|---|
| Идти в точку; атаковать врага | Щелчок по земле; щелчок по вражеской цели |
| Способность | **Q / W / E / R**, затем щелчок по точке или цели; также доступны кнопки HUD |
| Атака с продвижением | **A**, затем щелчок по земле |
| Остановиться | **S** |
| Вернуться на базу | **D**; канал 3 секунды, прерывается перемещением, атакой или получением урона |
| Магазин | **B**; покупать можно только рядом со своим Истоком, в радиусе 330 единиц |
| Вернуть камеру к герою | **Пробел** |
| Масштаб | Колесо мыши |
| Камера через миникарту | Щелчок по миникарте; правый щелчок либо Shift+щелчок отправляет героя в точку |
| Таблица игроков | Удерживать **Tab** |
| Отменить выбор способности / закрыть окно / открыть меню | **Esc** |

Меню останавливает **только автономный матч**. В сетевой игре бой продолжается, даже когда открыто меню или вкладка свёрнута. Герой погибает и возрождается; золото и опыт помогают усилить его предметами и уровнями. На базе восстанавливаются здоровье и мана. Башни и Исток защищены, пока не выполнены условия продвижения по линии.

## Герои и настройки

Астер — страж, Лира — поддержка, Синдер — стрелок, Торн — боец, Никс — убийца, Вольт — маг. У каждого четыре разные способности; описание, стоимость маны и восстановление доступны на карточках и в подсказках. В настройках есть звук, громкость, качество и уменьшение движения. Звук включается после взаимодействия с игрой; настройки сохраняются в браузере.

## Исходники, сборка и проверки

Основные файлы: `public/game-core.js` — симуляция; `public/renderer.js` — Canvas2D-графика; `public/app.js` — интерфейс, ввод и сеть; `public/index.html` и `public/styles.css` — разметка и стили. `server/rooms.mjs` реализует комнаты, `server/node-server.mjs` — локальный HTTP-сервер, `drizzle/` содержит схему D1.

Из папки проекта:

```text
node build.mjs
node --test
```

Сборка создаёт автономный `Emberfall.html`, Worker `worker/index.js` и каталог `dist` для упаковки. `npm test` сам выполняет сборку перед проверками, поэтому работает сразу после распаковки. При прямом запуске `node --test` сначала выполните `node build.mjs`. `npm run build`, `npm start` и `npm run start:lan` — сокращения команд сборки и запуска; зависимости не устанавливаются.

Серверные проверки включают реальную SQLite-схему и два независимых HTTP-клиента через два сервиса с общей базой: движение, урон через щит и по здоровью, одинаковое состояние, права ведущего, изоляцию комнат, защиту от повторных команд, CAS, лимиты и срок жизни. Это проверка локального сетевого пути; она не подтверждает работу облачного D1 или удалённой сети. Подробности API и размещения — в `server/DEPLOY_NOTES.md`.

## Публичное размещение

Игра опубликована отдельным публичным Site: https://emberfall-battle-for-origin.quietchub17.chatgpt.site. Платформа подтвердила успешное размещение версии 1, публичная страница отвечает без авторизации. Серверный Worker использует общую D1-базу через логическую привязку **DB** и схему из `drizzle`. Локальный сервер из launcher использует оперативную память.

Публичный облачный матч проверен двумя независимыми HTTPS-клиентами: создание комнаты и вход, запуск 5×5 с восемью ботами, покупки, защита от повторных команд, мана/щит/перезарядка, движение и настоящий урон с оглушением видны обоим игрокам. Все девять проверок прошли. Оба тестовых игрока вышли; последующий ответ `404 room_not_found` подтвердил удаление временной комнаты. Статические ресурсы сайта также проверены отдельно. Доступ с другого физического устройства ещё не проверялся. Автономный комплект работает независимо от размещения.

Проект использует собственные названия, процедурную графику и звук. Ассеты и код Valve не используются.
