# Emberfall 3D — Битва за Исток

Отдельная трёхмерная версия Emberfall. Адрес новой версии в Sites: https://emberfall-3d.quietchub17.chatgpt.site (личный доступ владельца). Исходная 2D-игра сохранена: https://emberfall-battle-for-origin.quietchub17.chatgpt.site.

В новой версии поле боя, герои, воины, башни и Истоки состоят из объёмных WebGL-моделей. Перспективная камера вращается вокруг поля. Освещение, тени, туман и анимации работают в реальном времени. Портреты и обычные элементы интерфейса остаются плоскими, как в других 3D-играх.

Правила боя перенесены из прошлой игры: три линии, 5×5, шесть героев и 24 способности, покупки, уровни, смерть/возрождение и разрушение вражеского Истока. Свободные места занимают боты. Сетевой сервер использует ту же авторитетную симуляцию, а браузер показывает её в 3D.

## Без интернета

Откройте `Emberfall3D.html` или `START_OFFLINE.cmd`. Установка Node.js не нужна. Three.js, игровая логика, графика и звук включены в файл; внешние ресурсы не загружаются. Нужен современный браузер с WebGL и включённым аппаратным ускорением. При отсутствии WebGL игра показывает понятное сообщение.

## Управление

- Щелчок по земле — движение; по врагу — атака.
- Q / W / E / R — выбрать способность, затем щёлкнуть по цели.
- Z / C — повернуть 3D-камеру. Зажатое колесо мыши и движение мышью — обзор. Кнопки камеры доступны на экране.
- Колесо — приблизить или отдалить. Пробел — камера к герою.
- A — атака по пути, S — остановиться, D — возврат на базу.
- B — магазин, Tab — счёт, Esc — отмена или меню.

## Локальный сетевой режим

Нужен Node.js 22.13+. Запустите `START_SERVER.cmd`, откройте http://127.0.0.1:4173. Выберите «По сети», создайте комнату. Во второй вкладке введите её код и присоединитесь. Создатель начинает матч, пустые места занимают боты. На другом устройстве адрес 127.0.0.1 указывает на него самого: для общей доверенной сети используйте START_LAN.cmd и IPv4 компьютера ведущего. Launcher не меняет брандмауэр. Закрытие сервера удаляет локальные комнаты.

## Сборка и исходники

Внешние npm-зависимости не нужны. Из каталога проекта:

```
node build.mjs
node --test
```

`npm test` сам выполняет сборку. `public/renderer.js` — новый 3D-рендерер, `public/renderer-portraits.js` — сохранённый код портретов и миникарты. `public/game-core.js` и `server/rooms.mjs` — игровая и сетевая логика прошлой Emberfall. Сборка создаёт `Emberfall3D.html` и Worker ESM для Sites. D1-схема находится в `drizzle/`.

Three.js r160 включена локально из официального репозитория https://github.com/mrdoob/three.js. MIT-лицензия сохранена в `public/vendor/THREE-LICENSE.txt` и в заголовке библиотеки. Модели, названия и игровая логика — оригинальные; ассеты Valve не используются.
