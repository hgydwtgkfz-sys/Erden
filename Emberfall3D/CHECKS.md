# Проверка Emberfall 3D

Новая версия построена в отдельном каталоге. Исходные файлы 2D-игры сверены по SHA256 и сохранены. Игровой движок `game-core.js` и сервер комнат `rooms.mjs` перенесены без изменений; визуализация заменена на Three.js/WebGL.

## Выполнено

- Настоящий WebGL в браузере: объёмная карта, башни, лес, герои, перспективная камера. Поворот и изменение наклона проверены кнопками. Щелчок по земле перемещает героя; камера следует за ним. Способность W показывает щит, списывает ману и запускает 15-секундное восстановление. Ошибок JavaScript при этих действиях не обнаружено. Снимок `screenshots/01_3d_match.png` сделан в настоящем браузере 1280×720.
- Четыре проверки 3D-рендерера: 1080 обратных преобразований экрана и земли при 216 сочетаниях угла, масштаба и размера окна; настоящая перспективная глубина; объёмные модели из 35-секундного состояния BattleCore; выбор поднятой модели лучом под четырьмя углами; исключение погибших и скрытых целей. Проверены смена героя при повторном матче, повторное использование моделей и освобождение ресурсов. В этих программных проверках заменяется только GPU; настоящая отрисовка проверена отдельно браузером.
- Проверки интерфейса, всех 24 способностей, полного боя ботов, магазина, возрождения и результата сохранены. Сетевые проверки используют два независимых HTTP-клиента и SQLite с интерфейсом D1. Проверки Worker сравнивают отданные файлы с исходниками, включая Three.js и код портретов.
- Обычный `npm test` сам собирает проект. Опциональные live-скрипты не запускаются без явного флага; они указывают на отдельный адрес 3D-игры и отдельный файл отчёта, сохраняя отчёт прошлой 2D-версии.

## Повторить

Node.js 22.13+, без установки npm-пакетов:

```
node build.mjs
node --test
```

Для запуска автономного варианта достаточно `Emberfall3D.html` и браузера с WebGL. Все скрипты и полная MIT-лицензия Three.js встроены в HTML. Архив дополнительно содержит исходники, отдельную лицензию и Windows-launcher.

Новая облачная публикация создаётся отдельно с личным доступом владельца. Облачный сетевой матч именно на этом новом Site и соединение с другого физического устройства отдельно не проверялись; прежний публичный 2D-матч проверен своим отчётом. Эти результаты не подменяют друг друга.
